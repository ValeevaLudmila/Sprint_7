# 🚀 Sprint 7 — API тестирование Яндекс Самокат

В этом спринте проект полностью посвящён **тестированию API учебного сервиса Яндекс Самокат**.

Документация API: [qa-scooter.praktikum-services.ru/docs](https://qa-scooter.praktikum-services.ru/docs/)

---

## 🎯 Цели проекта

* Проверка работы всех критичных ручек API: курьеры, авторизация, заказы.
* Автоматизация тестов с генерацией уникальных данных для независимости тестов.
* Визуализация тестов через **Allure Reports**.
* Проверка успешных сценариев и корректной обработки ошибок.

---

## 🛠 Используемые технологии

* Python 3.x
* **requests** — HTTP-запросы к API
* **pytest** — написание структурированных и параметризованных тестов
* **Allure** — визуализация запросов и ответов
* Faker — генерация уникальных данных курьеров

---

## 📂 Структура проекта

```
tests/
    test_create_courier.py          # создание курьера, проверка дублирования и ошибок
    test_login_courier.py           # авторизация курьера
    test_delete_courier.py          # удаление курьера и проверка ошибок
    test_make_order.py              # создание заказов с различными параметрами цветов
    test_accept_the_order.py        # принятие заказа курьером и проверка ошибок
    test_get_order_by_number.py     # получение заказа по треку
    test_get_order_list.py          # проверка списка заказов

conftest.py                         # фикстуры для курьеров и заказов
data.py                              # константы, тестовые данные и ожидаемые ответы
urls.py                              # URL эндпоинтов API
generators.py                        # генерация логина, пароля, имени
```

---

## ⚡ Быстрый старт

```bash
# Установить зависимости
pip install -r requirements.txt

# Запуск всех тестов с записью результатов
pytest --alluredir=allure-results

# Генерация и просмотр Allure отчёта
allure serve allure-results
```

## ✅ Основные сценарии тестов

### Курьер

* Создание нового курьера
* Ошибка при попытке создать дублирующего курьера
* Проверка обязательных полей для регистрации
* Авторизация курьера
* Ошибки при отсутствующих полях или несуществующем пользователе
* Удаление курьера и обработка ошибок

### Заказ

* Создание заказов с разными цветами: BLACK, GREY, оба или без цвета
* Принятие заказа курьером, включая проверки ошибок: без ID курьера, несуществующий курьер, без ID заказа, несуществующий заказ
* Получение заказа по номеру трека и обработка ошибок
* Получение списка всех заказов с проверкой структуры ответа

## 💡 Преимущества

* Автоматизация всего API учебного сервиса
* Параметризация тестов и генерация данных гарантируют независимость каждого теста
* Allure отчёты дают визуализацию всех шагов с запросами и ответами
* Лёгкое масштабирование для добавления новых ручек или сценариев
